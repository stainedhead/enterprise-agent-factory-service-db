# User docs

For operators provisioning and running the Agent Factory database.

- [Getting started](getting-started.md): bootstrap the roles, apply the migrations, check the result,
  run the tests.
- [Configuration reference](configuration.md): `afs-migrate` options, session settings, runtime
  settings, database parameters and connection limits.
- [Operations](operations.md): scheduled jobs, applying a release, backups and restore,
  troubleshooting.
